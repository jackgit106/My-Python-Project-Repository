# Python Programming – Data Technician Bootcamp Project

## Project Overview

This project was completed as part of a **Data Technician Bootcamp** and focused on developing fundamental **Python programming and problem-solving skills**.

The project explored core Python concepts and demonstrated how programming can be used to build logical solutions, perform calculations, process information, and interact with users.

## Skills & Techniques

- **Variables** to store and manage data
- **`print()` function** to display information and results
- **`input()` function** to collect information and interact with users
- **Type casting** to convert data between types such as strings, integers, and floats
- **`if` statements** to create conditional logic and make decisions
- **`for` loops** to repeat actions and process multiple items
- **`while` loops** to repeatedly execute code while a condition is met
- Building logical programs using a combination of Python fundamentals
- Performing calculations and manipulating user-provided data

## Key Tasks

- Created variables to store different types of information
- Used `input()` to collect user information and create interactive programs
- Applied `print()` to display messages, calculations, and program results
- Used type casting to convert user input into appropriate numerical data types
- Created `if` statements to make decisions based on different conditions
- Used `for` loops to efficiently repeat tasks and process data
- Applied `while` loops to control repeated actions and program flow
- Combined multiple programming concepts to build functional solutions
- Performed calculations using user-provided values and variables

## Logic & User Interaction

The project demonstrated how Python can be used to create programs that respond to **user input and changing conditions**.

By combining variables, calculations, conditional statements, and loops, I developed programs capable of making decisions, repeating tasks, and producing dynamic results based on user interaction.

## Outcome

This project strengthened my foundational skills in **Python programming, logical thinking, problem-solving, user interaction, and data manipulation**.

It provided practical experience building simple programs from individual Python concepts and combining them to create functional, interactive solutions.
